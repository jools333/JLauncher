# JLauncher 🚀

**JLauncher** — быстрый, легковесный и кроссплатформенный аналог **Ulauncher** и **Albert**, разработанный на **Rust**.

Приложение предназначено для **Linux (X11 и Wayland)** и **Windows**. Оно висит в системном трее, мгновенно вызывается по нажатию глобального хоткея (`Alt+Space` по умолчанию) и предоставляет доступ к калькулятору, поиску и запуску установленных программ, а также командам управления питанием компьютера.

---

## ✨ Возможности

1. **Красивое всплывающее поле ввода по центру экрана**:
   - Минималистичный современный интерфейс в стиле Raycast / Ulauncher.
   - Закругленные углы, акцентная подсветка, фокус ввода сразу при открытии.
   - Быстрая навигация с клавиатуры: стрелки `↑` / `↓` для выбора, `Enter` для запуска, `Esc` для скрытия.
   - Подсказки хоткеев и статусные уведомления (например, при копировании результата).

2. **Встроенный математический калькулятор**:
   - Поддерживает стандартные арифметические операции (`+`, `-`, `*`, `/`, скобки).
   - Поддерживает проценты (например, `25% of 200`).
   - Поддерживает математические функции и константы (`math::sqrt(144)`, `math::sin(pi/2)`, `pi`, `e`, `abs(-42)`).
   - Префикс `=` для явного вычисления произвольных выражений (например, `= 1024 * 768`).
   - Нажатие `Enter` мгновенно копирует вычисленный результат в буфер обмена.

3. **Поиск и запуск установленных приложений**:
   - **Linux**: сканирует стандартные пути XDG (`/usr/share/applications`, `~/.local/share/applications`, Flatpak, Snap), парсит `.desktop` файлы с поддержкой локализованных русских названий (`Name[ru]`), описаний и иконок.
   - **Windows**: сканирует меню «Пуск» (общий каталог и каталог пользователя), находит `.lnk` ярлыки и встроенные системные утилиты (Блокнот, Диспетчер задач, Параметры, PowerShell, Терминал, Проводник).
   - Быстрый нечеткий поиск (Fuzzy Matcher) по алгоритму Skim/Fzf с ранжированием по релевантности.

4. **Команды управления системой**:
   - **Выключение**: `shutdown`, `poweroff`, `выключить`, `выключение`, `питание`
   - **Перезагрузка**: `reboot`, `restart`, `перезагрузка`, `перезагрузить`
   - **Блокировка экрана**: `lock`, `lock screen`, `заблокировать`, `блокировка`
   - **Выход из сеанса**: `logout`, `sign out`, `выйти`, `завершить сеанс`
   - **Спящий режим**: `sleep`, `suspend`, `сон`, `спящий режим`
   - Поддерживает `systemctl` / `loginctl` на Linux и нативные команды на Windows.

5. **Системный трей и окно настроек**:
   - Иконка в системном трее с контекстным меню:
     - 🔍 *Открыть лаунчер*
     - ⚙ *Настройки...*
     - 🔄 *Обновить программы*
     - ❌ *Выход*
   - Клик по иконке трея также открывает/скрывает лаунчер.
   - В окне настроек можно:
     - Изменить глобальную горячую клавишу (например, `Alt+Space`, `Ctrl+Space`, `Super+Space`).
     - Включить или выключить флаг автозапуска при старте системы.
     - Настроить количество отображаемых результатов.
     - Включать/отключать калькулятор и системные команды.
     - Очищать или сохранять поисковый запрос при скрытии.
     - Запустить принудительное пересканирование каталога программ.

6. **Полная поддержка Linux (X11 и Wayland)**:
   - В сессиях **X11** и **XWayland** работает фоновый глобальный перехватчик хоткеев.
   - В строгих сессиях **Wayland** (GNOME, KDE Plasma, Sway, Hyprland) безопасность запрещает приложениям перехватывать глобальные нажатия клавиш вне фокуса. Для этого в JLauncher встроен **IPC-демон**: достаточно назначить в настройках окружения вызов команды `jlauncher --toggle` на желаемый хоткей. Окно мгновенно появится на экране.

## 📥 Установка

### Windows
1. Перейдите в [GitHub Releases](https://github.com/jools333/JLauncher/releases) и скачайте файл инсталлятора **`JLauncher_<version>_x64-setup.exe`** (или `jlauncher-setup.exe`).
2. Запустите инсталлятор. Он автоматически установит программу, создаст ярлыки в меню «Пуск» и на рабочем столе, а также добавит запись в системное меню Windows «Установка и удаление программ».
3. При необходимости доступна и портативная standalone-версия (`jlauncher-windows-x86_64.exe`).

### Linux

#### Установка через deb-пакет (Ubuntu, Debian, Mint, Pop!_OS):
1. Скачайте **`jlauncher_<version>_amd64.deb`** (или `jlauncher_amd64.deb`) со страницы [Releases](https://github.com/jools333/JLauncher/releases).
2. Установите пакет командой:
   ```bash
   sudo apt install ./jlauncher_*_amd64.deb
   ```
   *Пакет автоматически установит бинарник в `/usr/bin/jlauncher`, установит иконки и добавит пункт в меню приложений системы (`jlauncher.desktop`).*

#### Ручная установка / другие дистрибутивы:
Скачайте готовый архив `jlauncher-v<version>-linux-x86_64.tar.gz` или бинарный файл со страницы [Releases](https://github.com/jools333/JLauncher/releases) и скопируйте исполняемый файл в `/usr/local/bin` или `~/.local/bin`.

## 🛠 Сборка и запуск

### Требования
- **Rust** 1.75+ (`rustc`, `cargo`).
- **Linux зависимости** (для сборки графики и трея):
  ```bash
  # Ubuntu / Debian:
  sudo apt install build-essential libx11-dev libxext-dev libxft-dev \
                   libxinerama-dev libxcursor-dev libxrender-dev \
                   libxfixes-dev libgtk-3-dev libayatana-appindicator3-dev
  ```

### Сборка
```bash
# Сборка debug-версии:
cargo build

# Сборка оптимизированной release-версии:
cargo build --release
```

Исполняемый файл будет доступен в:
- Windows: `target/release/jlauncher.exe`
- Linux: `target/release/jlauncher`

## 💻 Использование

### Запуск приложения
```bash
# Обычный запуск (открывает окно и садится в трей):
jlauncher

# Запуск в фоновом режиме (только системный трей, без показа окна):
jlauncher --hidden
```

### Управление через командную строку (IPC)
```bash
jlauncher --toggle    # Переключить видимость окна (показать / скрыть)
jlauncher --show      # Показать лаунчер
jlauncher --hide      # Скрыть лаунчер
jlauncher --settings  # Открыть настройки
jlauncher --quit      # Завершить запущенный экземпляр
```

## 🐧 Настройка в Wayland (Ubuntu / GNOME / KDE / Sway / Hyprland)

В композиторах Wayland глобальные комбинации клавиш настраиваются на уровне системы:

1. Откройте **Параметры системы** -> **Комбинации клавиш** (Keyboard Shortcuts).
2. Нажмите **Добавить собственную комбинацию** (Custom Shortcut).
3. Укажите:
   - **Имя**: `JLauncher`
   - **Команда**: `jlauncher --toggle`
   - **Комбинация клавиш**: `Alt+Space` (или `Super+Space`)
4. Примените изменения. Теперь при нажатии хоткея лаунчер будет мгновенно открываться и скрываться.

## 📂 Структура проекта

```
src/
├── main.rs            # Точка входа, обработка аргументов CLI, запуск IPC и GUI
├── app.rs             # Основной интерфейс eframe/egui, навигация с клавиатуры
├── coordinator.rs     # Координатор видимости и фокуса окна (Win32 ShowWindow / X11)
├── config.rs          # Хранение настроек в JSON (хоткей, автозапуск, лимиты)
├── calculator.rs      # Математический движок evalexpr, проценты и константы
├── system.rs          # Команды питания (Shutdown, Reboot, Lock, Logout, Sleep)
├── hotkey.rs          # Модуль регистрации глобальных горячих клавиш
├── tray.rs            # Иконка системного трея и контекстное меню
├── ipc.rs             # Локальный TCP IPC-сервер и клиент для одиночного экземпляра
└── apps/
    ├── mod.rs         # Индекс приложений и алгоритм нечеткого поиска (Skim/Fzf)
    ├── linux.rs       # Сканирование и запуск .desktop файлов в Linux
    └── windows.rs     # Сканирование и запуск ярлыков и утилит в Windows
```
